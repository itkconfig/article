# 🐧 สอนอ่านหน้า Help ของคำสั่ง ip ฉบับคนเริ่มจาก 0
> **อ่านจบ... ใช้งานเป็นทันที!**

สำหรับคนที่เพิ่งเริ่มจับ Linux การต้องพิมพ์คำสั่งยาวๆ บนหน้าจอดำๆ อาจจะดูน่ากลัวครับ ยิ่งเป็นคำสั่งเกี่ยวกับ Network อย่างคำสั่ง `ip` (ที่ใช้ดู IP, ดูการ์ดแลน, หรือตั้งค่าเร้าเตอร์) หลายคนมักจะใช้วิธี **"จำ"** หรือ **"ก๊อปปี้จากเน็ตมาแปะ"**

แต่ความจริงแล้ว คนทำงานระบบ (Sysadmin) ไม่มีใครจำได้ทุกคำสั่งครับ **"พวกเขาแค่รู้วิธีอ่านหน้า Help"**

บทความนี้จะสอนวิธี **"ถอดรหัส"** หน้าคู่มือ (Help) ของคำสั่ง `ip` แบบจับมือทำ เริ่มจาก 0 ก็เข้าใจได้ครับ!

---

## 🔹 ขั้นที่ 1: โครงสร้างของคำสั่ง ip และการเรียกดูคู่มือ

คำสั่ง `ip` บน Linuxไม่ได้ทำงานเดี่ยวๆ แต่มันมี **"หมวดหมู่ย่อย (Object)"** ให้เราเลือกจัดการ เช่น:

- `ip address` — จัดการหมายเลข IP
- `ip link` — จัดการตัวการ์ดแลน/อินเตอร์เฟซ
- `ip route` — จัดการเส้นทางอินเทอร์เน็ต

### 💡 วิธีเรียกดูคู่มือ (Help)
- **ถ้าอยากดูภาพรวมทั้งหมด:**
  ```bash
  ip help
  ```
- **ถ้าอยากดูวิธีใช้เฉพาะหมวด IP:**
  ```bash
  ip address help
  ```

> **เทคนิค:** พิมพ์คำสั่งที่ต้องการ แล้วตามด้วยคำว่า `help` เสมอ

---

## 🔹 ขั้นที่ 2: ถอดรหัส "สัญลักษณ์ลับ" ในหน้า Help

เมื่อคุณพิมพ์ `ip address help` คุณจะเจอกับข้อความยุ่บยั่บเหมือนภาษาต่างดาว นี่คือกฎ 4 ข้อที่จะไขความลับของสัญลักษณ์เหล่านี้ครับ:

1. **คำที่เป็น "ตัวพิมพ์เล็ก" = คำสั่งบังคับ**
   - ต้องพิมพ์แบบนั้นเป๊ะๆ ห้ามเปลี่ยน เช่น `show`, `add`, `dev`, `scope`
2. **คำที่เป็น "ตัวพิมพ์ใหญ่ทั้งหมด" = ตัวแปร (Placeholder)**
   - มันคือ "ช่องว่าง" ที่รอให้คุณเอาค่าจริงๆ ไปใส่แทนที่ เช่น:
     - `IFNAME` (Interface Name) = ให้ใส่ชื่อการ์ดแลนจริงๆ เช่น `eth0` หรือ `ens160`
     - `PREFIX` = ให้ใส่ IP พร้อม Subnet เช่น `192.168.1.10/24`
3. **เครื่องหมายวงเล็บเหลี่ยม `[ ... ]` = ตัวเลือกเสริม (Optional)**
   - แปลว่า "จะพิมพ์ลงไป หรือไม่พิมพ์ก็ได้" ถ้าไม่พิมพ์ ระบบก็จะใช้ค่าพื้นฐานให้เอง
4. **เครื่องหมายปีกกาและเส้นคั่น `{ a | b }` = บังคับให้เลือกอย่างใดอย่างหนึ่ง**
   - คุณต้องเลือกตัวใดตัวหนึ่งในปีกกานั้น เช่น `{ up | down }` แปลว่าคุณต้องพิมพ์คำว่า `up` หรือไม่ก็พิมพ์ `down` เท่านั้น

---

## 🔹 ขั้นที่ 3: ลองของจริง! (ประกอบร่างคำสั่ง)

มาลองดูบรรทัดตัวอย่างจากหน้า Help ของจริงกันครับ:

```text
ip address show [ dev IFNAME ] [ { up | down } ]
```

### 🔍 แปลความหมายทีละส่วน:
- `ip address show` : เป็นตัวพิมพ์เล็ก แปลว่าเราต้องพิมพ์เป๊ะๆ (คำสั่งขอดู IP)
- `[ dev IFNAME ]` : อยู่ในวงเล็บเหลี่ยม แปลว่า **"จะระบุการ์ดแลนหรือไม่ก็ได้"** ถ้าระบุ คำว่า `dev` ต้องพิมพ์เป๊ะๆ ส่วน `IFNAME` เป็นพิมพ์ใหญ่ ให้เปลี่ยนเป็นชื่อการ์ดแลน เช่น `dev ens160`
- `[ { up | down } ]` : เป็นวงเล็บเหลี่ยม แปลว่า **"จะระบุสถานะหรือไม่ก็ได้"** แต่ถ้าจะระบุ ต้องเลือกแค่อย่างใดอย่างหนึ่ง คือ `up` (เปิดทำงาน) หรือ `down` (ปิดทำงาน)

---

### 💻 ตัวอย่างการประยุกต์ใช้งาน

#### แบบที่ 1: ขี้เกียจพิมพ์เยอะ ไม่ใส่ตัวเลือกเสริมเลย (ข้ามวงเล็บเหลี่ยมไปให้หมด)
```bash
ip address show
```
*(ผลลัพธ์: แสดง IP ของการ์ดแลนทุกใบในเครื่อง)*

#### แบบที่ 2: อยากดู IP เฉพาะการ์ดแลนที่ชื่อ ens160
```bash
ip address show dev ens160
```
*(ผลลัพธ์: โชว์ข้อมูลเฉพาะของการ์ดแลนใบนั้น)*

#### แบบที่ 3: อยากดู IP เฉพาะการ์ดแลนที่ชื่อ ens160 และมีการ เปิดทำงาน (up) อยู่เท่านั้น
```bash
ip address show dev ens160 up
```

## 💡 สรุปเคล็ดลับวิชา

- **ไม่ต้องท่องจำคำสั่ง!** แค่จำว่าอยากทำอะไรกับอะไร แล้วพิมพ์ `help` ต่อท้าย (เช่น `ip route help`)
- **สแกนหาคำสั่งหลัก** ที่เป็นตัวพิมพ์เล็ก
- **ดูว่าสิ่งที่เราอยากทำ** มันไปตรงกับตัวเลือกในวงเล็บ `[ ]` อันไหน
- **ถ้าเจอตัวพิมพ์ใหญ่** ให้หาของจริงมาแทนที่ (เช่น เปลี่ยน `IFNAME` เป็นชื่อการ์ดแลน)
