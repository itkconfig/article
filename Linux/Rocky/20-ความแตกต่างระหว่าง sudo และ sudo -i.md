# ความแตกต่างระหว่าง sudo และ sudo -i

การใช้งานคำสั่ง **sudo** และ **sudo -i** มีความแตกต่างหลักอยู่ที่**การโหลดตัวแปรสภาพแวดล้อม (Environment Variables)** และ**ตำแหน่งโฟลเดอร์ปัจจุบัน (Current Working Directory)** [1]

## 1. การทำงานของคำสั่ง sudo

คำสั่ง **sudo** (ตามด้วยคำสั่งที่ต้องการรัน) ใช้สำหรับยืมสิทธิ์ root เพื่อรันคำสั่งใดคำสั่งหนึ่งเพียงชั่วคราว เช่น `sudo systemctl restart sshd` [1]

* **Environment Variables:** จะยังคงรักษาค่าตัวแปรสภาพแวดล้อมบางส่วนของผู้ใช้เดิมเอาไว้ โดยตัวแปรอย่าง `$HOME` หรือ `$PATH` บางตัวอาจไม่ถูกเปลี่ยนเป็นของ root แบบ 100% [1]
* **Current Working Directory:** ตำแหน่งโฟลเดอร์ปัจจุบันจะยังคงเป็นโฟลเดอร์เดิม ณ ตอนที่พิมพ์คำสั่ง [1]

## 2. การทำงานของคำสั่ง sudo -i

คำสั่ง **sudo -i** ใช้สำหรับเปลี่ยนสถานะเป็น root แบบเต็มรูปแบบ (Simulate Initial Login) เสมือนว่าผู้ใช้ root เป็นคนพิมพ์รหัสผ่านล็อกอินเข้ามาในระบบเองตั้งแต่แรก [2]

* **Environment Variables:** ระบบจะโหลดโปรไฟล์ของ root ใหม่ทั้งหมด โดยจะอ่านไฟล์ตั้งค่าต่างๆ ของ root เช่น `.profile`, `.bash_profile` หรือ `.bashrc` มาใช้งาน [2]
* **Current Working Directory:** ระบบจะย้ายตำแหน่งโฟลเดอร์ปัจจุบันไปยัง Home Directory ของ root (คือ `/root`) โดยอัตโนมัติ [2]

## 3. สรุปแนวทางการเลือกใช้งาน

* **เลือกใช้ sudo:** เพียงพอเมื่อต้องการแค่ใช้สิทธิ์ root จัดการไฟล์ในโฟลเดอร์ปัจจุบัน [2]
* **เลือกใช้ sudo -i:** เหมาะกับงานที่ต้องอ้างอิงตัวแปรสภาพแวดล้อมหรือเส้นทาง (Path) ที่ตั้งค่าไว้เฉพาะสำหรับ root ซึ่งจะช่วยเพิ่มความมั่นใจและป้องกันข้อผิดพลาดได้ดีกว่า [2]
