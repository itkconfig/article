# อธิบายกฎในไฟล์ sudoers

สองบรรทัดนี้เป็นกฎในไฟล์ **sudoers** (`/etc/sudoers`) ของ Linux/Unix ใช้กำหนดว่าใครสามารถรันคำสั่งอะไรด้วยสิทธิ์ของใครบ้าง มาอธิบายทีละบรรทัดครับ

---

## บรรทัดที่ 1

```sudoers
newuser ALL=(ALL) /usr/bin/htop, /usr/sbin/reboot
```

**รูปแบบ:** `ผู้ใช้  host=(ผู้ใช้เป้าหมาย) คำสั่ง`

| ส่วน | ความหมาย |
|------|----------|
| `newuser` | ชื่อผู้ใช้ที่จะได้รับสิทธิ์ |
| `ALL` (ตัวแรก) | ใช้ได้กับทุก host (ทุกเครื่องในเครือข่าย) |
| `(ALL)` | สามารถรันในนามของผู้ใช้คนใดก็ได้ (รวมถึง root) |
| `/usr/bin/htop, /usr/sbin/reboot` | คำสั่งที่อนุญาตให้รันได้ (เฉพาะ 2 คำสั่งนี้เท่านั้น) |

**แปลว่า:** ผู้ใช้ `newuser` สามารถใช้ `sudo` รันคำสั่ง `/usr/bin/htop` และ `/usr/sbin/reboot` ได้ด้วยสิทธิ์ root (หรือผู้ใช้อื่น) — แต่**ทำอย่างอื่นไม่ได้** (เช่น `sudo rm`, `sudo apt` จะถูกปฏิเสธ)

ตัวอย่างการใช้งาน:

```bash
sudo htop              # ✅ ได้
sudo reboot            # ✅ ได้
sudo vim /etc/passwd   # ❌ ไม่ได้
```

## บรรทัดที่ 2

```sudoers
%wheel  ALL=(ALL)       ALL
```

| ส่วน | ความหมาย |
|------|----------|
| `%wheel` | กลุ่มชื่อ `wheel` (เครื่องหมาย `%` นำหน้าหมายถึง **กลุ่ม** ไม่ใช่ผู้ใช้) |
| `ALL` (ตัวแรก) | ทุก host |
| `(ALL)` | รันในนามผู้ใช้คนใดก็ได้ |
| `ALL` (ตัวสุดท้าย) | **ทุกคำสั่ง** |

**แปลว่า:** สมาชิกทุกคนในกลุ่ม `wheel` สามารถใช้ `sudo` รันคำสั่ง**อะไรก็ได้** ด้วยสิทธิ์ของผู้ใช้คนใดก็ได้ (ปกติคือ root) — เทียบเท่าเป็น superuser เต็มรูปแบบ

ตัวอย่าง:

```bash
sudo anything    # ✅ ได้หมด
```

> นี่คือบรรทัดมาตรฐานในดิสโทรอย่าง RHEL/CentOS/Fedora (ใน Ubuntu/Debian มักใช้กลุ่ม `sudo` แทน)

---

## สรุปเปรียบเทียบ

| ประเด็น | `newuser` | `%wheel` |
|---------|-----------|----------|
| ขอบเขต | ผู้ใช้คนเดียว | ทั้งกลุ่ม |
| คำสั่งที่ทำได้ | จำกัดแค่ `htop`, `reboot` | ทุกคำสั่ง |
| ระดับสิทธิ์ | เท่ากับ root เฉพาะ 2 คำสั่ง | root เต็มรูปแบบ |

**แนวคิดด้านความปลอดภัย:** บรรทัดแรกคือการให้สิทธิ์แบบ **จำกัด (least privilege)** — ให้เท่าที่จำเป็น ส่วนบรรทัดที่สองคือการให้สิทธิ์ **เต็มรูปแบบ** แก่กลุ่มผู้ดูแลระบบ

> 💡 **ข้อควรระวัง:** ควรแก้ไขไฟล์ sudoers ด้วย `visudo` เท่านั้น เพื่อป้องกัน syntax error ที่อาจทำให้ sudo ใช้ไม่ได้ทั้งหมด
