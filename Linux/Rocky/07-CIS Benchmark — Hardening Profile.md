# CIS Benchmark — Hardening Profiles

ในเอกสาร **CIS Benchmark** จะแบ่ง Profile การ Hardening ออกเป็น 2 ระดับหลัก ได้แก่ **Level 1** และ **Level 2**

---

## 🟢 Level 1 — ความปลอดภัยขั้นพื้นฐานทั่วไป

**Level 1** เป็นระดับการ Hardening พื้นฐานที่เหมาะสำหรับระบบทั่วไป โดยมีแนวคิดว่า:

- 🔐 เน้นความปลอดภัยที่ใช้งานได้จริง (**Prudent and Practical**)
- 🛡️ ให้ประโยชน์ด้านความปลอดภัยที่ชัดเจน
- ⚙️ ไม่กระทบหรือขัดขวางการทำงานปกติของระบบ
- 💻 โดยทั่วไปไม่กระทบต่อการทำงานของระบบและ Application ส่วนใหญ่
- ✅ ทุกระบบควรพิจารณานำ Level 1 มาใช้เป็น **มาตรฐานเริ่มต้นของการ Hardening**

### แนวคิดสำคัญ

Level 1
│
├── Security Improvement
├── Prudent & Practical
├── Low Impact
└── เหมาะสำหรับระบบทั่วไป

> 🎯 **เป้าหมาย:** เพิ่มความปลอดภัยโดยไม่สร้างผลกระทบต่อการใช้งานระบบมากเกินไป

---

## 🔴 Level 2 — ความปลอดภัยระดับเข้มงวดสูง

**Level 2** เป็นระดับการ Hardening ที่เข้มงวดกว่า Level 1 และเป็นมาตรการเพิ่มเติมสำหรับระบบหรือองค์กรที่ให้ความสำคัญกับ Security เป็นอย่างมาก

แนวคิดหลัก ได้แก่:

- 🔐 เป็นมาตรการเพิ่มเติมจาก **Level 1**
- 🛡️ เน้นการป้องกันเชิงลึกหลายชั้น (**Defense-in-Depth**)
- 🚨 เหมาะสำหรับสภาพแวดล้อมที่ **Security is paramount**
- ⚠️ อาจส่งผลกระทบต่อ **Performance**
- ⚠️ อาจลดความสะดวกในการใช้งานระบบ (**Usability**)
- ⚠️ อาจต้องทดสอบ Compatibility กับ Application ก่อนนำไปใช้งานจริง

### แนวคิดสำคัญ

Level 2
│
├── Level 1
│   └── Basic Security
│
├── Additional Security Controls
├── Defense-in-Depth
├── Higher Security
└── อาจมี Performance / Usability Impact

> 🎯 **เป้าหมาย:** เพิ่มระดับการป้องกันให้สูงขึ้นสำหรับระบบที่มีความเสี่ยงหรือมีข้อกำหนดด้าน Security สูง

---

## ⚖️ เปรียบเทียบ Level 1 และ Level 2

| หัวข้อ | 🟢 Level 1 | 🔴 Level 2 |
|---|---|---|
| ระดับความเข้มงวด | พื้นฐาน | เข้มงวดสูง |
| แนวคิด | Prudent and Practical | Security is paramount |
| เป้าหมาย | เพิ่ม Security โดยกระทบน้อย | เพิ่ม Security สูงขึ้น |
| ผลกระทบต่อระบบ | ต่ำ | อาจสูงกว่า |
| Performance | โดยทั่วไปกระทบน้อย | อาจกระทบ |
| Usability | โดยทั่วไปไม่กระทบมาก | อาจลดความสะดวก |
| Defense-in-Depth | พื้นฐาน | เน้นมากขึ้น |
| เหมาะสำหรับ | ระบบทั่วไป | ระบบสำคัญ / ความเสี่ยงสูง |

---

CIS Benchmark

│   ├── Prudent & Practical

│   └── ระบบทั่วไป
│
└── 🔴 Level 2
    ├── Advanced Hardening
    ├── Security is Paramount

    ├── อาจกระทบ Performance

## 📌 สรุป

### 🟢 Level 1

> **"เพิ่มความปลอดภัย โดยไม่รบกวนการทำงานปกติของระบบ"**

เหมาะสำหรับ:

- 🖥️ Server ทั่วไป
- 💻 Workstation
- 🏢 ระบบ Production ทั่วไป
- 🌐 ระบบที่ต้องการ Security Baseline

### 🔴 Level 2

> **"เพิ่มความปลอดภัยให้สูงขึ้น แม้อาจต้องแลกกับ Performance หรือ Usability"**

เหมาะสำหรับ:

- 🔐 ระบบที่มีความสำคัญสูง
- 🛡️ ระบบที่มีความเสี่ยงสูง
- 🏦 ระบบที่มีข้อกำหนดด้าน Security เข้มงวด
- 🚨 ระบบที่ต้องการ Defense-in-Depth

---

## 💡 แนวทางการใช้งาน

โดยทั่วไปควรเริ่มต้นจาก **Level 1** ก่อน แล้วจึงประเมิน:

1. ความเสี่ยงของระบบ
2. ความสำคัญของระบบ
3. ข้อกำหนดด้าน Security
4. ผลกระทบต่อ Performance
5. ผลกระทบต่อ Application
6. ผลกระทบต่อผู้ใช้งาน

หากระบบมีความต้องการด้าน Security สูง และสามารถยอมรับผลกระทบที่อาจเกิดขึ้นได้ จึงพิจารณาเพิ่มมาตรการ **Level 2**

---

> 🔑 **จำง่าย ๆ:**  
> **Level 1 = Secure + Practical**  
> **Level 2 = Maximum Security + Defense-in-Depth**
